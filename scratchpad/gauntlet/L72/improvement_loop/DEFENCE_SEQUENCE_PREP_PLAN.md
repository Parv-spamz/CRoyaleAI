# Defense sequence preparation, October 5

Prepare an index into the existing historical **training** data while N2 awaits
adequate fresh Icebow evidence. This is data preparation, not a successor training
run or a registered final experiment. No checkpoint, optimizer, prediction,
sampling mixture, policy input or live behavior changes in this step.

Use the hash-verified training-only defensive-X-Bow audit and its original
calibrated labels. For every audited bow, index all existing same-replay,
same-side Icebow training rows from two seconds before placement through thirty
seconds after placement, inclusive (20 ticks/second). The two-second lead-in
preserves nearby expert decisions before the investment; the thirty-second
follow-up matches the previously declared primary descriptive horizon. Preserve
terminal/truncated windows and windows with no Rocket, unknown outcomes or damage.
Never select on a future Rocket, win, coverage flag, cost or tower result.

Store row IDs and per-window offsets only. Bind the original dataset and all
supervision-array hashes; never regenerate PLAY/WAIT, card, aim, wait or value
targets. This exposes the existing causal per-decision history, not a new
recurrent sequence model. Do not invent rows missing from the source dataset.
Record original row counts, gaps, label composition and overlapping membership.
Provide deduplicated defensive and other-window row unions and the full original
training pool, so later sampling cannot accidentally multiply a row's weight by
the number of overlapping bows. Do not choose a sampling ratio yet.

Verify independently against original training bow labels, not the audit's
future-outcome columns or builder's interval function. Require exact per-window
row equality, intact original supervision, no held-out replay/row membership and
exact unions. Exercise positive controls and corrupted membership, side, split,
boundary, duplication and label controls. Outcome annotations are descriptive
only and must not enter the index arrays or model input path.

This prepares one candidate data treatment for a later ordinary-IL versus
defense-sequence-exposure comparison. A usable cohort, power/multiplicity design,
fixed budget/initialization and development selection rule must still be frozen
before any training. Preserve all existing N2-N7 and replacement gates. Both-lane
and post-Rocket response measurements remain required for gameplay acceptance.
